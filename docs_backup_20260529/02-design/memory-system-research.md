# 记忆系统技术调研

**版本**: v2.0  
**最后更新**: 2026-05-13

---

## 调研背景

Agent 需要记忆系统来存储和检索信息，但 LLM 的上下文窗口有限。

---

## 技术方案

### 向量数据库

| 方案 | 优点 | 缺点 |
|------|------|------|
| FAISS | 轻量、快速 | 功能有限 |
| Chroma | 易用、功能全 | 性能一般 |
| Pinecone | 云服务、可扩展 | 成本高 |

### 选型结论

选择 FAISS 作为向量检索引擎：
- 本地部署，无网络依赖
- 性能优秀，适合中小规模
- Python 生态完善
