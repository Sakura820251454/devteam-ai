## 1. 项目愿景

DevTeam-AI 是一个多智能体协同开发平台，旨在模拟真实软件开发团队的协作模式。

**核心架构**：

- **Agent 人才库**：无预设角色，任务驱动临时职责。每个 Agent 通过 soul.md 定义四维个性（性格、沟通、决策、风险），固定统筹 Agent 主导协作
- **分层记忆系统**：L1/L2/L3 三层私有记忆 + 独立共享向量存储，框架自动管理记忆生命周期
- **灰盒任务调度**：用户发布任务 + 验收结果，框架和 Agent 自行完成计划、拆解、分配、执行。内部过程对用户透明
- **多 Agent 协作**：统筹 Agent 主持讨论，Agent 民主讨论技术方案，分歧由用户最终裁决
- **人类干预**：随时主动介入，聊天框自然语言交互，三核心场景（纠错暂停、结果重做、需求变更）
- **自我学习**：大任务验收后复盘，三条路径沉淀知识（SKILL.md 技能文件、soul 优化、知识库）

该平台特别适合以下场景：
- 个人开发者借助 AI 团队完成中小型项目开发
- 初创团队在有限资源下快速验证产品原型
- 技术爱好者探索多 Agent 协作的工程实践

---

## 2. 核心价值

### 2.1 效率提升

多 Agent 并行工作模式能够将复杂的开发任务分解为多个子任务，由不同的专业 Agent 同时处理，大幅缩短项目周期。

### 2.2 成本优化

通过 Prompt 缓存、上下文压缩、智能模型路由等技术，配合 DeepSeek 等国产低成本大模型，将 API 调用成本控制在可接受范围内。

### 2.3 质量保障

每个开发阶段都产出对应的文档，任务状态全程可追踪，出现问题时能够快速定位原因。

### 2.4 能力积累

系统自动从讨论和任务执行中提取知识，形成可复用的知识库和技能库，使系统随使用不断进化。

---

## 3. 核心设计理念

> **「文档驱动、工具赋能、持续进化」**

- **文档驱动**：确保每个开发环节都有可追溯的产出
- **工具赋能**：通过 MCP 和 Skill 的即插即用架构，让 Agent 能够像专业团队成员一样「持证上岗」
- **持续进化**：通过知识沉淀和自我学习，使系统越用越智能
