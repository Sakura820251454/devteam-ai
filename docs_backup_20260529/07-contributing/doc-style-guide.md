# 文档风格指南

**最后更新**: 2026-05-14

---

## 文档分类

项目文档分为 7 个分类：

| 编号 | 分类 | 说明 |
|------|------|------|
| 01 | 项目概览 | 项目愿景、架构、原则、术语表 |
| 02 | 设计文档 | 产品设计、技术调研、设计规格、ADR |
| 03 | 开发指南 | 环境搭建、编码规范、测试指南 |
| 04 | 模块文档 | 代码模块文档（与代码一一对应） |
| 05 | API 文档 | REST API 接口文档 |
| 06 | 路线图 | 开发规划和阶段划分 |
| 07 | 贡献指南 | 贡献流程、文档规范、代码规范 |

---

## 文档规范

### 文件命名

- 使用小写字母和连字符：`agent-service.md`
- ADR 使用日期前缀：`2026-05-13-title.md`

### 文档结构

每个文档应包含：

1. 标题和最近更新日期
2. 概述
3. 主要内容
4. 相关文档链接

### Markdown 格式

- 使用 ATX 风格标题
- 代码块指定语言
- 表格使用标准格式

### 代码-文档同步

- 新增代码模块时，必须在 `scripts/doc_sync_config.json` 中添加映射
- 修改代码接口时，同步更新对应文档
- CI 会运行 `doc_sync.py --check` 检查同步状态
