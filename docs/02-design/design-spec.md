## 1. 项目概述

DevTeam-AI 是一个多智能体协同开发平台，模拟真实软件开发团队的协作模式。

---

## 2. 核心组件

### 2.1 Agent 系统

- Agent 人才库模式，无预设角色，任务驱动临时职责
- Soul 文件四维个性定义（性格、沟通、决策、风险）
- 独立上下文空间
- 固定统筹 Agent 主导协作

### 2.2 记忆系统

- L1 工作记忆 / L2 短期记忆 / L3 长期记忆（Agent 私有）
- 独立向量存储（团队共享）
- CrewAI Cognitive Memory 五操作模型
- 自动晋升 + 复盘手动触发双轨流转

### 2.3 任务系统

- 五阶段 Pipeline：需求分析 → 拆解 → DAG 并行 → 互审 → 验收
- 统筹 Agent 分配，多维风险评级
- 灰盒模型：用户只需关注输入和结果
