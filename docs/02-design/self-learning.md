# 自我学习设计

**版本**: v2.0  
**日期**: 2026-05-13  
**状态**: 正式版  

---

## 1. 学习机制

### 知识提取

从对话和任务执行中提取有价值的知识。

### 技能沉淀

将成功的解决方案转化为可复用的技能。

### 经验积累

记录成功和失败的经验教训。

---

## 2. 学习流程

```
执行任务 → 收集数据 → 提取知识 → 验证知识 → 存储知识
```

---

## 3. 知识类型

| 类型 | 说明 | 存储位置 |
|------|------|----------|
| 领域知识 | 专业领域的知识 | L3 长期记忆 |
| 技能知识 | 可复用的操作技能 | 技能库 |
| 经验知识 | 成功/失败的经验 | L2/L3 记忆 |

---

## 4. 知识应用

### 自动应用

系统自动匹配相关知识辅助决策。

### 手动检索

Agent 主动检索知识库。

### 推荐学习

系统推荐 Agent 学习新知识。
