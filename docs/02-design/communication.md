---

## 1. 通信模式

| 模式 | 说明 | 可见性 |
|------|------|--------|
| **公共讨论** | 所有 Agent 在公共频道中讨论，消息对全体可见 | 全员 |
| **私聊** | 用户与单个 Agent 的私密对话 | 仅双方 |
| **任务频道** | 特定任务的消息流 | 任务相关 Agent |
| **广播** | 系统向所有 Agent 发送通知 | 全员 |

---

## 2. 消息可见性原则

- **全员可读**：公共讨论消息所有 Agent 都能看到
- **按相关发言**：Agent 只能发布与当前任务相关的消息，不能发无关消息
- **统筹控场**：统筹 Agent 控制发言权，决定谁能发言

---

## 3. 发言控制

### Token 预算管理

- 控制每次发言的最大 Token 数
- 跟踪会话级 Token 使用量
- 80% 使用率时触发警告

### 频率控制

- 限制 Agent 每分钟最大发言次数
- 可配置的最小发言间隔
- 防止 Agent 刷屏和资源浪费

### 辩论上限

- 同一议题设定辩论轮次上限
- 超上限自动上报用户裁决
- 平衡讨论充分性和 Token 成本

---

## 4. 消息类型

| 类型 | 说明 |
|------|------|
| `text` | Agent 文本消息 |
| `system` | 系统通知消息 |
| `action` | 操作消息（如任务状态变更） |
