# 通信机制

**版本**: v2.0  
**日期**: 2026-05-13  
**状态**: 正式版  

---

## 1. 通信模式

### 公共讨论

所有 Agent 在公共频道中讨论，信息对所有 Agent 可见。

### 私聊

用户与单个 Agent 的私密对话，其他 Agent 不可见。

### 广播

系统向所有 Agent 发送通知消息。

---

## 2. 消息类型

| 类型 | 说明 |
|------|------|
| `text` | 文本消息 |
| `system` | 系统消息 |
| `task` | 任务相关消息 |
| `notification` | 通知消息 |

---

## 3. 发言控制

### Token 预算

控制每次发言的最大 Token 数。

### 发言队列

管理 Agent 的发言顺序。

### 频率控制

限制 Agent 的发言频率，避免刷屏。
