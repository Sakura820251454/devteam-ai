**状态**: 正式版  

---

## 1. 协作模式

### 并行协作

多个 Agent 同时处理不同的子任务。

### 串行协作

Agent 按顺序处理任务，前一个 Agent 的输出作为后一个 Agent 的输入。

### 讨论-决策

Agent 们讨论后达成共识，做出决策。

---

## 2. 协作流程

```
任务分解 → 分配子任务 → 并行执行 → 结果合并 → 验证完成
```

---

## 3. 协作规则

### 信息共享

Agent 之间共享必要的上下文信息。

### 冲突解决

当 Agent 意见不一致时，通过投票或人工干预解决。

### 进度同步

定期同步各 Agent 的执行进度。
