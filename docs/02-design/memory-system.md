# 分层记忆系统设计

**版本**: v2.0  
**日期**: 2026-05-13  
**状态**: 正式版  

---

## 1. 设计背景

Agent 在执行任务时需要依赖上下文信息，但 LLM 的上下文窗口有限，不可能将所有历史信息都加载进来。

分层记忆系统通过将信息按重要性和时效性分层，实现：
- 信息的高效存储和检索
- 上下文窗口的合理利用
- 长期知识的沉淀和复用

---

## 2. 记忆层级架构

```
┌─────────────────────────────────────────────────────────────┐
│ L1 工作记忆 - 当前会话的即时记忆                              │
│ • 最近 N 条对话                                              │
│ • 任务中间结果                                               │
│ • 临时计算状态                                               │
│ 生命周期：会话期间                                           │
├─────────────────────────────────────────────────────────────┤
│ L2 短期记忆 - 最近会话的摘要                                  │
│ • 会话摘要                                                   │
│ • 重要决策记录                                               │
│ • 成功/失败经验                                              │
│ 生命周期：5-10 次会话                                        │
├─────────────────────────────────────────────────────────────┤
│ L3 长期记忆 - 持久化的知识库                                  │
│ • 核心技能                                                   │
│ • 领域知识                                                   │
│ • 成功案例                                                   │
│ 生命周期：永久                                               │
├─────────────────────────────────────────────────────────────┤
│ L4 向量检索 - 语义级别的知识检索                              │
│ • 经验向量索引                                               │
│ • 技能向量索引                                               │
│ • 知识图谱                                                   │
│ 生命周期：永久                                               │
└─────────────────────────────────────────────────────────────┘
```

---

## 3. 记忆操作

### 添加记忆

| 层级 | 触发时机 |
|------|----------|
| L1 | 每次对话后 |
| L2 | 会话结束时 |
| L3 | 定期归档 |
| L4 | 向量索引更新 |

### 检索记忆

| 层级 | 检索方式 |
|------|----------|
| L1 | 直接读取 |
| L2 | 模糊匹配 |
| L3/L4 | 向量检索 |

### 清理策略

- **LRU**：最近最少使用
- **时间衰减**：按时间降低权重
- **价值评估**：按重要性评分

---

## 4. 层级对比

| 层级 | 名称 | 用途 | 生命周期 |
|------|------|------|----------|
| L1 | 工作记忆 | 当前会话的即时记忆 | 会话期间 |
| L2 | 短期记忆 | 最近会话的摘要 | 5-10 次会话 |
| L3 | 长期记忆 | 持久化的知识库 | 永久 |
| L4 | 向量检索 | 语义级别的知识检索 | 永久 |
