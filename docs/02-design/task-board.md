## 1. 看板结构

```
┌─────────────┐ ┌─────────────┐ ┌─────────────┐ ┌─────────────┐
│   待处理    │ │   进行中    │ │   审核中    │ │   已完成    │
│  (pending)  │ │ (executing) │ │ (reviewing) │ │ (completed) │
├─────────────┤ ├─────────────┤ ├─────────────┤ ├─────────────┤
│  任务卡片   │ │  任务卡片   │ │  任务卡片   │ │  任务卡片   │
│  任务卡片   │ │  任务卡片   │ │             │ │  任务卡片   │
│  任务卡片   │ │             │ │             │ │  任务卡片   │
└─────────────┘ └─────────────┘ └─────────────┘ └─────────────┘
```

---

## 2. 任务卡片

每个任务卡片包含：

| 字段 | 说明 |
|------|------|
| 标题 | 任务名称 |
| 描述 | 任务详情 |
| 负责人 | 分配的 Agent |
| 优先级 | 高/中/低 |
| 标签 | 分类标签 |
| 截止日期 | 完成期限 |

---

## 3. 看板操作

### 拖拽移动

用户可以拖拽任务卡片在不同列之间移动。

### 任务创建

点击添加按钮创建新任务。

### 任务详情

点击任务卡片查看详细信息。
