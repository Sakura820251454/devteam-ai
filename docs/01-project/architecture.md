## 2. 分层职责

### 2.1 用户交互层

负责与用户的直接交互：
- Agent 团队选择界面
- 公共讨论区
- 私聊区
- 任务看板
- 强制干预面板

### 2.2 应用接口层

提供 REST API 接口：
- Agent 管理接口
- 任务管理接口
- 消息总线接口
- 会话管理接口

### 2.3 讨论控制层

控制 Agent 的发言行为：
- Token 预算控制
- 发言队列管理
- 发言频率控制
- Agent 状态管理

### 2.4 记忆与存储层

管理 Agent 的记忆系统：
- L1 工作记忆
- L2/L3 长期记忆
- 外部知识库
- 审计日志

### 2.5 扩展能力层

提供可扩展的能力：
- MCP 工具注册
- Skill 管理器
- 知识库管理器
- 技能库管理器

### 2.6 LLM 适配器层

支持多种 LLM 模型：
- DeepSeek
- 智谱 GLM
- 通义千问
- 本地模型

### 2.7 成本优化层

优化 API 调用成本：
- Prompt 缓存
- 上下文压缩器
- 智能模型路由
- 批量处理器

## 3. 技术选型

| 层级 | 技术选型 | 理由 |
|------|----------|------|
| 后端 | Python 3.11+ / FastAPI | 高性能、异步支持 |
| 前端 | React 18 / TypeScript | 生态成熟、类型安全 |
| 数据库 | SQLite / PostgreSQL | 轻量/成熟 |
| LLM | DeepSeek | 国产低成本高性能 |
| 向量检索 | FAISS | 轻量、支持本地部署 |
