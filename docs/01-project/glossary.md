**版本**: v2.0

## 核心概念

| 术语 | 英文 | 定义 |
|------|------|------|
| Agent | Agent | 具有特定能力和角色的 AI 智能体 |
| Skill | Skill | Agent 可使用的技能，如代码审查、文档生成 |
| MCP | Model Context Protocol | 模型上下文协议，用于扩展 Agent 能力 |
| Soul | Soul | Agent 的性格和角色定义文件 |

---

## 记忆系统

| 术语 | 英文 | 定义 |
|------|------|------|
| L1 记忆 | Working Memory | 工作记忆，当前会话的短期记忆 |
| L2 记忆 | Session Memory | 会话记忆，跨会话的中期记忆 |
| L3 记忆 | Long-term Memory | 长期记忆，持久化的知识 |
| L4 记忆 | External Knowledge | 外部知识库，RAG 检索 |

---

## 任务管理

| 术语 | 英文 | 定义 |
|------|------|------|
| Task | Task | 开发任务，可分配给 Agent |
| Pipeline | Pipeline | 任务流水线，定义任务执行顺序 |
| Stage | Stage | 流水线阶段 |
