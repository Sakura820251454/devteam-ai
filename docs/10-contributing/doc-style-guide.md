## 文档规范

### 文件命名

- 使用小写字母和连字符：`agent-service.md`
- ADR 使用日期前缀：`2026-05-13-title.md`

### 文档结构

每个文档应包含：

1. 标题和版本信息
2. 概述
3. 主要内容
4. 相关文档链接

### Markdown 格式

- 使用 ATX 风格标题
- 代码块指定语言
- 表格使用标准格式
